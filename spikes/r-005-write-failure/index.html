R-005 write / recovery probe

このページは 実機の keymap を書き換えます。手順 1 の backup を保存するまで write 系のボタンは押せません。書き換えるのは下で指定した 1 箇所だけです。 終了時は手順 7 で必ず元の値へ戻してください。

0. device を選ぶ

WebHID の権限は origin 単位で、port も origin に含まれる。R-004（:8173）で 許可済みでも、この origin（:8175）では初回の getDevices() は 必ず 0 件になる。requestDevice で選び直す。

1. backup を取る（必須）

read フロー全体を実行して JSON で保存する。これが唯一の復元元になる。

2. 書き換える 1 箇所を決める

既定は layer 9 の (0,0)。definition が宣言していて、かつ baseline.vil では KC_NO の位置を選んである。

3〜4. write して即座に読み直す

5. 電源を切って戻す

ケーブルを抜くだけでは足りない。Cornix LP は battery を積んでいるため、USB を抜いても動き続けることがある。電源スイッチを切る（または battery を外す）こと。RAM が生きたままだと、flash に載っていない値をそのまま読んでしまう。

電源を入れ直したら下のボタンを押す。uptime が巻き戻っていなければ再起動していないので、その回の結果は捨てる。

6. write の直後に切断する

押した直後にケーブルを抜く。write が途中で切れたときに何が残るかを見る。 再接続してから手順 5 のボタンで確認する。

7. 元に戻す（必須）

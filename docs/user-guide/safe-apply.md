# Safe Apply と復旧

Apply は workspace と実機の差分だけを Cornix LP へ書き込む操作です。
実行には Web UI、実機接続、最新の読み取り、人間による差分確認が必要です。

## 安全原則

実機の安全を保護するため、Cornix Bonsai は以下の原則で書き込みを行います。

1. **書き込み前の自動退避**: Apply 開始時に、現在の実機状態を自動でバックアップします。
2. **手動確認の必須化**: 計算された差分を人間が確認するまで書き込みません。
3. **1 件ずつの検証**: 書き込み直後に実機から再読み込みし、値の一致を検証します。
4. **失敗時の中断**: 途中で切断や不一致が発生した場合、その場で処理を中断します。続きから推測で再開しません。

## Apply 前の確認手順

Apply を実行する前に、以下を順番に確認します。

1. 画面上部に正しい workspace 名が表示されていることを確認します。
2. 対象の Cornix LP へ接続されていることを確認します。
3. `実機から再読み込み` を実行し、最新の実機状態を取得します。
4. エラー・警告の件数と、実機との差分件数を確認します。
5. 想定外の UID や definition 不一致がある場合は、Apply を中止します。

接続しただけでは最新状態を取得していません。
必ずその接続セッションで `実機から再読み込み` を完了させてください。

## Apply の実行手順

1. 画面下部の `実機へ Apply…` を選びます。
2. `cornix/backups/` へバックアップが保存されたことを確認します。
3. ダイアログの `書き込む差分` で変更前後の値を確認します。
4. 警告がある場合は、内容を理解した項目だけ承認します。
5. エラーが 0 件で差分が意図通りなら、書き込みボタンを押します。
6. 完了するまで実機を切断せず、書き込みと検証の進捗を待ちます。

## 診断の重要度と判断基準

画面に表示される診断は、重要度によって扱いが異なります。

| 重要度             | Apply への影響     | 対処方針                                                           |
| ------------------ | ------------------ | ------------------------------------------------------------------ |
| **エラー (error)** | Apply 不可（停止） | 設定または接続先を修正します。確認操作で無視することはできません。 |
| **警告 (warning)** | 要手動確認         | 内容を確認し、意図した変更であれば個別に承認します。               |
| **情報 (info)**    | Apply 可能         | 状態の説明です。Apply は妨げられません。                           |

警告の承認は、問題を解決したことを意味しません。
設定や差分が更新されると、以前の承認は自動で取り消されます。

## 中断・切断・検証失敗時の復旧

Apply 中に中断、切断、タイムアウト、検証不一致が起きた場合は、途中から再開しません。

1. 実機を再接続します。
2. `実機から再読み込み` を実行し、最初から実機状態を取得し直します。
3. 新しい実機状態と workspace から、差分を再計算します。
4. 再計算された差分を確認し、改めて Apply を実行します。

途中まで書き込まれた内容は、新しい読み取り結果へ正しく反映されます。

## バックアップからの復元

Apply 直前の状態は `cornix/backups/latest.vil` に保存されます。
画面上部の `backup から復元` を選ぶと、バックアップを workspace へ読み戻せます。

1. `backup から復元` を選びます。
2. 読み込まれたキーマップと差分を確認します。
3. 通常の手順に従い、差分確認と承認を経て Apply を実行します。

バックアップを選んだ時点では、実機は書き換わりません。
通常の Apply と同様に差分確認を経て実機へ反映します。

## 永続化の確認

Apply 完了時に保証されるのは、実機のメモリへ反映されたことと直後の照合一致です。
ファームウェアによるフラッシュメモリへの保存完了までは確認できません。

電源切断後も設定が保持されるか確認したい場合は、以下の手順を行います。

1. Apply 完了後に Cornix LP の電源を入れ直します。
2. 再接続して `実機から再読み込み` を実行します。
3. 差分が 0 件であることを確認します。

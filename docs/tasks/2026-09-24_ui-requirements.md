# Web UI 要件（UI 刷新の入力）

Web UI を作り直すための要件を、現在の画面構成から切り離して並べる。
画面の分け方、配置、部品の境界は要件ではなく、刷新の設計で決める。
刷新の比較は uiux-numa の Experiment で行い、判断は ADR に残す。

出典は `docs/user-guide/`、`docs/specs/`（ui、apply-flow、validation、workspace-cli、mac-keymap）、ADR 0004〜0030、`docs/tasks/ai-logs/` である。
各項目の ID は、刷新後の検証表で参照する。

## 利用者と前提

- 利用者は Cornix LP と MacBook を持つ個人で、Git と AI エージェントを併用する。
- 対応環境は macOS の Chrome / Chromium だけである（WebHID と File System Access API が必要）。
- 目標状態の正本は Git 管理の `keymap.yaml` と `mac-keyboard.<layout>.yaml` で、UI は CLI と AI の編集経路の 1 つである。
- 編集は実機を接続しなくても成立する。
  実機が要るのは、初期化の取り込み、差分の確認、Apply のときだけである。

## 作業

## 状態

UI はすべての状態を描き分ける。
色だけで区別せず、文字、icon、境界を併用する。

| ID   | 対象               | 状態                                                                                                           |
| ---- | ------------------ | -------------------------------------------------------------------------------------------------------------- |
| T-01 | 保存（ファイル別） | idle / saving / saved / error / conflict。1 か所にまとめて示すときの優先順は conflict > error > saving > saved |
| T-02 | 保存の失敗         | error は再試行できる。conflict は再試行を出さず、未保存の編集が失われた警告と再読込の導線を出す                |
| T-03 | workspace          | 未選択 / 権限の再確認が必要 / 開いている                                                                       |
| T-04 | Cornix の読み込み  | ready / `keymap.yaml` が無い / 旧 digest binding / その他の失敗。Cornix の失敗は Mac の編集を止めない          |
| T-05 | Mac の配列         | 配列ごとに ready / missing / error                                                                             |
| T-06 | 実機               | 未接続 / 接続済み（製品名）/ 読込済み（差分件数）。current / desired の UID と definition の一致               |
| T-07 | 診断               | error（常に Apply を止める）/ warning（Apply の確認時だけ承認できる。根拠の値が変わると承認が外れる）/ info    |
| T-08 | Apply の可否       | workspace 未選択、未接続、未読込、差分 0 件、error ありのどれかで開始できない。理由を示す                      |
| T-09 | Apply の段階       | backup / 差分確認 / 確認 / 書き込み / 結果。書き込みの開始前はキャンセルでき、開始後は「中断」だけにする       |
| T-10 | 選択               | 未選択 / key / encoder / Mac のキー。未選択なら picker 全体を無効にする                                        |
| T-11 | 作業の可否         | 選んだ対象で使えない作業がある（Mac では Overview と Behaviors が無い）                                        |
| T-12 | 補助操作の可否     | Cornix が ready でなければ VIL 読込・書出と backup 復元を使えない。再読込は directory が開いていれば使える     |

## 守る制約

UI の刷新でも次は変えない。

| ID   | 制約                                                                                                                | 出典                   |
| ---- | ------------------------------------------------------------------------------------------------------------------- | ---------------------- |
| C-01 | ファイル形式（`keymap.yaml`、`cornix/` 配下、`mac-keyboard.<layout>.yaml`、`.vil` の round-trip）と CLI             | ADR 0009、specs        |
| C-02 | 盤面の座標は `src/render/geometry.ts` が唯一の定義元。encoder の凡例座標を物理位置として描かない                    | ADR 0002 / 0011、ui.md |
| C-03 | keycode の表示は共通の label 関数から描き、ラベル表を UI へ複製しない。layer を指す keycode は layer 名を出す       | ADR 0012 / 0015、ui.md |
| C-04 | picker は編集対象を知らず、選んだ keycode を返すだけにする。Mac は `macKeycodeSupport` で選べない cell を無効にする | ADR 0025、ui.md        |
| C-05 | Apply は途中で他の作業へ移れない線形の流れにする。中断したら full read からやり直す                                 | ADR 0008 / 0011        |
| C-06 | Apply の結果を「保存した」「永続化した」と言わず、「実機に反映した」と書く。電源断後に残るかは未確認だと明示する    | ADR 0005 / 0008        |
| C-07 | 進捗は往復回数で出し、残り時間を推定しない（USB と BLE を区別できない）                                             | ADR 0004               |
| C-08 | device chooser の入口は常に出す。UI 側で `HIDDevice` を持たない                                                     | ADR 0004               |
| C-09 | warning の承認は Apply の確認時だけ行う。severity を UI の都合で変えない                                            | ADR 0010 / 0011        |
| C-10 | Settings は qsid 辞書で表示し、辞書に無い qsid は raw 表記を残す                                                    | ADR 0010               |
| C-11 | UI から `karabiner.json` に触れない。Browser で内蔵配列を検出しない                                                 | ADR 0022 / 0027        |
| C-12 | 表示名の変更は validation、差分、Apply fingerprint に影響しない                                                     | ADR 0012               |
| C-13 | 文字のコントラストは 4.5:1、focus と control の境界は 3:1 以上                                                      | ui.md                  |
| C-14 | 盤面は方向キーで隣のキーへ移り、Enter で編集へ入り、Esc で盤面へ戻る                                                | ADR 0011               |
| C-15 | GitHub Pages で配布し、設定やバックアップを外部へ送らない                                                           | ADR 0020               |

## 刷新の設計で決めること

次は要件ではない。
刷新の比較で案ごとに決める。

- 作業の分け方と並べ方（現行は対象 × 作業の 4 項目）
- 補助操作の置き場所と、常に見せる範囲
- 盤面、picker、編集 panel、診断の配置と大きさの配分
- 保存状態と Apply の入口の位置
- 部品の境界と状態の持ち方（現行は `src/ui/main.tsx` に集中している）

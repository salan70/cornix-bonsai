# 2026-08-19 D-006 UI / Interaction Designを確定する

対象Issue: #12 `[D-006] UI / Interaction Designを確定する`

## 調査方法

- ADR 0001〜0010の影響節から、UIへ送られていた制約を洗い出した
- Notion `01 プロダクト要件 & UX` / `02 技術アーキテクチャ & データモデル` の
  既存方針と、`04 競合調査 & 参考資料` の参照対象を確認した
- `src/core/`の実出力を使ってwireframeを描いた。Spikeは作っていない

## Fact

- リポジトリにfrontendは1行も存在しない。`package.json`の依存はTypeScriptと
  `@types/node`のみ、`src/`は`src/core/`だけ、`.tsx` / `.css`は無い
- `toPhysicalLayout(definition)`はCornix LPで**50 keyと4 encoder slot**を返す。
  親指の4キー（`3,4` `3,5` `7,5` `7,4`）だけが回転を持つ（±11.93° / ±23°）
- definitionのKLE上でencoderが持つ座標は`x` 15.25〜18.75で、盤面（`x` 0〜15）の外にある。
  **これは凡例の位置であって物理位置ではない**
- `describeKeycode("MO(2)")`は`押している間だけ layer 2`を返す。**layer名は含まない**
- `validateKeymap(baseline.vil, definition)`は`{error:0, warning:0, information:5}`で、
  5件はすべて`reachability/unreachable-layer`（layer 5〜9）
- `validateKeymap(invalid-cases.vil, definition)`は`{error:1, warning:5, information:1}`
- `describeSetting`は辞書が無いと`qsid 7: 180`を返す

## Decision

ADRを3つに分けて記録した。いずれも**状態: 採用**。

- `docs/decisions/0011-ui-structure.md`: 画面構成と編集interaction。
  workspaceを入口とする4 tab、Applyだけを線形modalへ分離、keymapはHTML/CSSの絶対配置、
  キー編集は右側の常設side panel、warning acknowledgeはApply確認stepでのみ行う
- `docs/decisions/0012-display-metadata.md`: layer名をApply対象外のsidecar
  `cornix/labels.yaml`へ置く。ADR 0009が持ち越した論点
- `docs/decisions/0013-frontend-foundation.md`: Vite + React + CSS Modules。
  component library・router・外部state管理を足さない

wireframeは[canvas](https://claude.ai/code/artifact/9ba207f6-5ce2-4b47-9195-773cb9e2a9ed)として
公開した。Git管理外のため、判断はADR本文が単独で読めるようにしてある。
盤面・keycode・診断の文言はすべて`fixtures/cornix-lp/`と`src/core/`の実出力を使った。

### ADR 0009から持ち越されていた論点

ADR 0009は「`.vil`に無いユーザー情報はv1では載せない」と決め、影響節で
「名前を持たせるにはADR 0006の『状態はraw 1つ』をraw + sidecarへ広げる判断が別途要る」と
先送りしていた。ADR 0011が`MO(2)`を「Nav」と表示すると決めた時点でこの判断が必要になり、
ADR 0012で解いた。sidecarは**stateではない**（実機へ書く経路もdiffで比較する経路も持たない）
ため、ADR 0006の前提は保たれている。

  2つのrendererのずれをどうtestで抑えるかは未検討

  対応をどう示すかが未検討
- layer名の重複・空文字を許すか。UIでの見分けも未検討
- browserで動くxz decoderの選定（ADR 0007から継続）
- 編集の衝突検出（file watchingを持たない前提、D-004から継続）

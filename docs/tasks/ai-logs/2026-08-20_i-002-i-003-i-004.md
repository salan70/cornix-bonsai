# I-002 / I-003 / I-004 MVP実装

## Fact

- Issue #13〜#15はworkspace/editor/CLI、WebHID adapter、Safe Apply UI統合を対象にしている。
- 実装前のリポジトリには`src/core/`だけがあり、frontend・workspace adapter・CLI・production device adapterは無かった。
- `fixtures/cornix-lp/`と既存Coreのround-trip / validation / Apply testは存在した。
- 実機USB/BLEのfull readとwriteは、この作業では実行していない。

## 実装

- Vite + React + TypeScriptのfrontendを追加し、4 tab、side panel、status bar、Apply modalを実装した。
- File System Access APIのdirectory handleをIndexedDBへ保存し、reload後に復帰するBrowser workspace adapterを追加した。
- Apply warningのacknowledge IDを`cornix/acknowledgements.json`へ保存し、最新backupの復元を通常のdesired/diff/Apply経路へ接続した。
- Behaviors tabにTap Dance / Combo / Settingsの直接編集を追加した。
- Node workspace adapterと`cornix validate/analyze/diff/render/export vil`、`.vil import` CLIを追加した。
- SVG/PDF rendererをdefinition由来の同一座標から生成するようにした。
- Vial report session、definition/full read、matrix由来layout、single-entry write + reread verify、timeout/disconnect境界を追加した。
- write未対応のmacro/unknown field/layout option差分はApplyをfatalで止め、I/O timeout/disconnect/protocol errorはaborted stateへ遷移させるようにした。
- xz definition decodeにはbrowser/Node対応の`xz-decompress`を使った。
- `MockHidDevice`でwrite command、再read verify、timeout、disconnectを自動検証した。
- Cornix LP V1.12のqsid辞書（9項目）をUI表示へ追加し、未知qsidはraw表記へフォールバックするようにした。
- Apply modalをnative`<dialog>`へ揃え、write開始後は中断だけを許可し、進行中I/O完了後に未完了分を破棄するようにした。
- Apply差分へqsid辞書を渡し、`notationOnly`差分を折りたたみ表示にした。Keymapのside panelにもsemanticな挙動説明を表示する。
